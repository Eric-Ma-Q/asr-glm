## 1. 项目介绍

### 核心功能

| 功能 | 说明 |
|------|------|
| 🎙️ **实时语音转录** | 对麦克风说话，实时显示文字（基于 GLM-ASR） |
| 📝 **录音管理** | 自动保存录音文件，支持播放、删除、编辑转写文本 |
| 🎤 **语音克隆** | 用录音提取音色，合成任意新文本（基于 GLM-TTS） |
| 🗂️ **声音库** | 管理所有克隆生成的语音，支持播放、下载、删除 |

### 技术栈

| 层 | 技术 |
|----|------|
| **前端** | React + Vite + Canvas 粒子动效 |
| **后端** | FastAPI + WebSocket + REST API |
| **ASR** | GLM-ASR-Nano-2512 (智谱语音识别) |
| **TTS** | GLM-TTS (智谱语音克隆) |

## 2. 环境要求

### 必须安装

| 软件 | 最低版本 | 下载地址 | 备注 |
|------|---------|---------|------|
| **Python** | 3.10+ | [python.org](https://www.python.org/downloads/) | 安装时勾选 "Add to PATH" |
| **Node.js** | 18+ | [nodejs.org](https://nodejs.org/) | 推荐 LTS 版本 |
| **Git** | 任意 | [git-scm.com](https://git-scm.com/downloads) | 用于下载模型 |

### 硬件要求

| 配置 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **内存** | 16GB | 32GB |
| **显卡** | NVIDIA 6GB 显存 | NVIDIA 12GB+ 显存 |
| **磁盘** | 15GB 空间 | 20GB+ 空间 |

> ⚠️ **注意**: 
> - ASR 功能可使用 CPU，但速度较慢
> - TTS 语音克隆功能**必须使用 GPU**，显存越大越好

## 3. 快速开始（5分钟版）

如果你是老手，直接按以下命令操作：

```powershell
# 1. 进入项目目录
cd G:\Project\glm-asr-project

# 2. 安装后端依赖
cd asr-python\backend
pip install -r requirements.txt

# 3. 安装前端依赖
cd ..\frontend
npm install

# 4. 启动后端（新终端）
cd G:\Project\glm-asr-project\asr-python\backend
python main.py

# 5. 启动前端（另一个新终端）
cd G:\Project\glm-asr-project\asr-python\frontend
npm run dev
```

然后打开浏览器访问: `http://localhost:5173`

## 4. 详细步骤

### 步骤 1: 检查环境

打开 **PowerShell** 或 **命令提示符**，输入以下命令检查：

```powershell
# 检查 Python
python --version
# 应输出: Python 3.10.x 或更高

# 检查 pip
pip --version

# 检查 Node.js
node --version
# 应输出: v18.x.x 或更高

# 检查 npm
npm --version

# 检查 Git（TTS 模型下载需要）
git --version
```

如果任何一项显示"无法识别"，请先安装对应软件。

---

### 步骤 2: 安装后端依赖

```powershell
# 进入后端目录
cd G:\Project\glm-asr-project\asr-python\backend

# 安装依赖
pip install -r requirements.txt
```

**依赖说明:**

| 类别 | 包名 | 用途 |
|------|------|------|
| **Web 框架** | `fastapi`, `uvicorn`, `websockets` | REST API + WebSocket 实时通信 |
| **核心** | `torch`, `torchaudio`, `transformers` | 深度学习框架 |
| **ASR** | `silero-vad`, `torchcodec` | 语音活动检测、音频编解码 |
| **TTS** | `soundfile`, `librosa`, `pypinyin` 等 | 语音合成依赖 |

> 💡 **提示**: 首次安装 `torch` 可能需要较长时间（约 1-5GB 下载量）

#### GPU 用户（可选优化）

如果你有 NVIDIA 显卡，建议安装 CUDA 版本的 PyTorch 以加速：

```powershell
# 卸载 CPU 版本
pip uninstall torch torchaudio

# 安装 CUDA 版本（以 CUDA 12.1 为例）
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
```

---

### 步骤 3: 安装前端依赖

```powershell
# 进入前端目录
cd G:\Project\glm-asr-project\asr-python\frontend

# 安装依赖
npm install
```

> ⏱️ 这一步通常需要 1-3 分钟，取决于网络速度。

## 5. GLM-TTS 模型管理（语音克隆功能）

> 🎤 GLM-TTS 用于语音克隆功能，模型较大（约 **8.3GB**），可按需下载/删除。
>
> ⚠️ 如果你只需要语音识别功能，可以跳过此章节。

### 模型文件位置与大小

模型存放在 `GLM-TTS/ckpt/` 目录下：

| 目录 | 文件 | 大小 | 用途 |
|------|------|------|------|
| `llm/` | model-00001-of-00002.safetensors | ~4.66 GB | LLM 主模型 |
| `llm/` | model-00002-of-00002.safetensors | ~1.12 GB | LLM 主模型 |
| `flow/` | flow.pt | ~859 MB | Flow 匹配模型 |
| `speech_tokenizer/` | model.safetensors | ~1.51 GB | 语音编码器 |
| `hift/` | hift.pt | ~80 MB | HiFi 声码器 |
| `vocos2d/` | generator_jit.ckpt | ~58 MB | Vocos 声码器 |
| **总计** | | **~8.3 GB** | |

---

### 下载模型（启用语音克隆功能）

模型托管在 [Hugging Face: THUDM/GLM-TTS](https://huggingface.co/THUDM/GLM-TTS)

#### 前置准备

```powershell
# 1. 安装 Git LFS（大文件支持）
git lfs install

# 2. 安装 Hugging Face CLI
pip install huggingface_hub
```

#### 下载模型

```powershell
# 进入 GLM-TTS 目录
cd G:\Project\glm-asr-project\GLM-TTS

# 方法 A：直接下载（需要良好的网络环境）
huggingface-cli download THUDM/GLM-TTS --local-dir ckpt

# 方法 B：使用镜像加速下载（推荐国内用户）
$env:HF_ENDPOINT = "https://hf-mirror.com"
huggingface-cli download THUDM/GLM-TTS --local-dir ckpt
```

#### 验证下载

下载完成后，确认以下文件存在：

```powershell
# 检查关键模型文件
Test-Path "G:\Project\glm-asr-project\GLM-TTS\ckpt\llm\model-00001-of-00002.safetensors"
Test-Path "G:\Project\glm-asr-project\GLM-TTS\ckpt\flow\flow.pt"
Test-Path "G:\Project\glm-asr-project\GLM-TTS\ckpt\speech_tokenizer\model.safetensors"
# 应全部返回 True
```

---

### 删除模型（释放磁盘空间）

如果暂时不需要语音克隆功能，可删除模型：

```powershell
# 方法 A：删除整个 ckpt 目录（推荐）
Remove-Item -Recurse -Force "G:\Project\glm-asr-project\GLM-TTS\ckpt"

# 方法 B：只删除大文件，保留配置
Remove-Item "G:\Project\glm-asr-project\GLM-TTS\ckpt\llm\model-*.safetensors" -Force
Remove-Item "G:\Project\glm-asr-project\GLM-TTS\ckpt\flow\flow.pt" -Force
Remove-Item "G:\Project\glm-asr-project\GLM-TTS\ckpt\speech_tokenizer\model.safetensors" -Force
Remove-Item "G:\Project\glm-asr-project\GLM-TTS\ckpt\hift\hift.pt" -Force
Remove-Item "G:\Project\glm-asr-project\GLM-TTS\ckpt\vocos2d\generator_jit.ckpt" -Force
```

## 6. 功能使用指南

### 6.1 实时语音转录

1. 打开浏览器访问 `http://localhost:5173`
2. 确保处于 **「实时转录」** Tab
3. 点击 **「开始录音」** 按钮
4. 浏览器会请求麦克风权限，点击允许
5. 对着麦克风说话，文字会实时显示
6. 点击 **「停止录音」** 结束
7. 录音会自动保存到 `asr-python/backend/recordings/` 目录

> 💡 点击「清除文本」可清空当前显示的转录文本

---

### 6.2 录音管理

1. 切换到 **「录音管理」** Tab
2. 在这里可以看到所有保存的录音：
   - ▶️ **播放**: 点击播放按钮试听录音
   - ✏️ **编辑**: 修改转写文本
   - 🎤 **克隆音色**: 发起语音克隆任务
   - 🗑️ **删除**: 删除录音文件

---

### 6.3 语音克隆

> ⚠️ 使用前请确保：
> 1. 已下载 GLM-TTS 模型（参见第 5 章）
> 2. 拥有 NVIDIA GPU (8GB+ 显存)

**操作步骤:**

1. 在 **「录音管理」** Tab 找到要使用的录音
2. 点击 **「加载 TTS 模型」** 按钮（首次使用需加载，需等待 1-2 分钟）
3. 点击录音项的 **「克隆音色」** 按钮
4. 在弹出的模态框中：
   - **提示文本**: 填写录音中说的话（用于提取音色）
   - **合成文本**: 填写要用克隆声音说的新内容
5. 点击 **「开始克隆」**
6. 等待进度条完成（通常 10-30 秒）
7. 完成后可直接试听克隆结果

---

### 6.4 声音库

1. 切换到 **「我的声音」** Tab
2. 以卡片形式展示所有克隆生成的语音
3. 每张卡片包含：
   - 📢 **内联播放器**: 支持播放/暂停、进度条
   - 📄 **合成文本**: 克隆时使用的文本
   - 🔗 **来源录音**: 使用的原始录音文件
   - 📥 **下载**: 保存为 WAV 文件
   - 🗑️ **删除**: 删除该克隆音频

## 7. 常见问题

### Q1: `pip` / `python` 不是内部命令

**原因**: Python 未添加到系统 PATH

**解决**:
1. 重新运行 Python 安装程序
2. 勾选 "Add Python to PATH"
3. 重启终端

---

### Q2: 安装 torch 失败或超时

**解决**: 使用国内镜像源

```powershell
pip install torch -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### Q3: 模型下载失败

**原因**: 网络问题无法访问 Hugging Face

**解决方案 A**: 使用镜像
```powershell
# 设置环境变量（临时）
$env:HF_ENDPOINT = "https://hf-mirror.com"

# 然后启动后端
python main.py
```

**解决方案 B**: 手动下载模型
1. 访问 [huggingface.co/zai-org/GLM-ASR-Nano-2512](https://huggingface.co/zai-org/GLM-ASR-Nano-2512)
2. 下载所有文件到本地目录
3. 修改 `model_loader.py` 中的模型路径为本地路径

---

### Q4: 端口被占用

**错误**: `Address already in use`

**解决**:
```powershell
# 查找占用端口的进程（以 8000 为例）
netstat -ano | findstr :8000

# 终止进程（用实际的 PID 替换 xxxxx）
taskkill /PID xxxxx /F
```

---

### Q5: 前端无法连接后端

**检查清单**:
1. ✅ 后端是否正常运行？（看终端输出）
2. ✅ 是否有防火墙阻止？
3. ✅ 后端地址是否正确？默认为 `ws://localhost:8000/ws/transcribe`

---

### Q6: GPU 未被使用（显示 Loading model on cpu）

**解决**: 确认 CUDA 版本的 PyTorch 已安装

```powershell
# 检查 PyTorch 是否支持 CUDA
python -c "import torch; print(torch.cuda.is_available())"
# 应输出: True
```

---

### Q7: TTS 模型加载失败

**可能原因**:
1. 模型未下载完整 → 参考第 5 章重新下载
2. 显存不足 → 需要 8GB+ 显存
3. transformers 版本不兼容 → 使用 `transformers==4.51.3`

**解决**:
```powershell
# 重新安装指定版本
pip install transformers==4.51.3
```

---

### Q8: 语音克隆效果不佳

**优化建议**:
1. **提示文本要准确**: 尽量完整、准确地填写录音中说的话
2. **录音质量要高**: 避免背景噪音，说话清晰
3. **录音时长适中**: 5-15 秒效果较好
