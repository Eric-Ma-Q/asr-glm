# 产品功能文档

## 1. 实时语音转录网页版

### 1.1 功能概述
基于 GLM-ASR 模型实现的网页端实时语音转录系统。用户可通过浏览器进行录音，系统将实时显示转录的文字内容，并伴有高保真的声波可视化效果。

### 1.2 核心特性
- **实时性**: 采用 WebSocket 流式传输，低延迟返回结果。
- **可视化**: 动态粒子波形，根据音量和频率实时跳动，提供沉浸式体验。
- **现代化 UI**: 采用深色玻璃拟态 (Glassmorphism) 设计风格，美观大气。
- **易用性**: 一键开始/停止录音，自动连接后端服务。

### 1.3 技术规格
- **前端**: React + Vite + Canvas API
- **后端**: FastAPI + WebSocket + PyTorch
- **模型**: GLM-ASR-Nano-2512 (1.5B 参数)
- **音频采样**: 16000Hz (单声道)
